FoodDecider

A web application that helps the user decide what to eat.

- Three meal options
- Option to choose between the choices
- 30-second timer
- User-friendly layout

- Java
- Spring Boot
- HTML
- CSS

FoodDecider was created to simplify the process of deciding what to eat. The application determines the meal choice.
An everyday problem-solver that settles conflicts!

The project provided experience in building a web application using Java
and Spring Boot, as well as creating a simple frontend with HTML and CSS.

1. Clone the repo
2. Open the project
3. Start the Spring Boot application

Open the application in your web browser and choose from the presented
meal options.
