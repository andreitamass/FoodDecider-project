FoodDecider

En webbapplikation som hjälper användaren att välja vad den ska äta.

- Tre maträttsalternativ
- Möjlighet att välja mellan alternativen
- 30 sekunders timer
- Användarvänlig layout

- Java
- Spring Boot
- HTML
- CSS

FoodDecider skapades för att underlätta sökandet för mat. Applikationen bestämmer vad man ska äta.
Ett vardagsproblem som löser konflikter!

Projektet gav erfarenhet av att bygga en webbapplikation med Java
och Spring Boot samt att skapa en enkel frontend med HTML och CSS.

1. Klona repot
2. Öppna projektet
3. Starta Spring Boot-applikationen

Öppna applikationen i webbläsaren och välj bland de presenterade
maträttsalternativen.
